# Phishing Email Detection Model

A machine learning web app (Scikit-learn + Flask) that classifies emails
as **Phishing** or **Safe**, using both TF-IDF text features and
hand-crafted structural red-flags (URL count, suspicious keywords,
urgency language, etc.). Displays accuracy and a confusion matrix from
model evaluation.

## Features
- **Dataset generator**: builds a labeled dataset (800 emails,
  balanced phishing/safe) from varied realistic templates
- **Feature extraction**: TF-IDF (word + bigram) combined with numeric
  features — URL count, IP-based URLs, suspicious keyword hits,
  requests for sensitive data (SSN, card numbers, etc.), exclamation
  count, uppercase ratio, and text length
- **Model**: Random Forest classifier trained via a Scikit-learn
  `Pipeline` + `FeatureUnion`
- **Evaluation**: accuracy, precision, recall, F1-score, and a
  confusion matrix (saved as an image and shown in the UI)
- **Web UI**: paste any email text and get an instant Phishing/Safe
  classification with a confidence score and the detected red-flag
  features, plus one-click sample emails to try

## Requirements
- Python 3.8+

## Setup & Run

1. Unzip the project and open a terminal in the project folder.
2. (Recommended) Create a virtual environment:
   ```
   python -m venv venv
   venv\Scripts\activate      # Windows
   source venv/bin/activate   # macOS/Linux
   ```
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Generate the training dataset:
   ```
   python generate_dataset.py
   ```
5. Train the model (this creates the model file, metrics, and the
   confusion matrix image used by the web UI):
   ```
   python train_model.py
   ```
6. Run the web app:
   ```
   python app.py
   ```
7. Open your browser at:
   ```
   http://127.0.0.1:5002
   ```

## How it Works
1. `generate_dataset.py` creates realistic phishing and legitimate
   email examples (varied senders, subjects, and bodies) and saves
   them with labels to `data/emails.csv`.
2. `train_model.py` splits the data 80/20, trains a TF-IDF + numeric
   feature Random Forest pipeline, evaluates it on the held-out set,
   and saves the model, metrics, and a confusion matrix plot.
3. `app.py` loads the trained model and exposes `/api/classify` —
   paste any email text and it returns a label, confidence score, and
   a breakdown of the red-flag features detected (URLs, suspicious
   keywords, sensitive-data requests, etc.).

## Notes
- The dataset is synthetically generated for demonstration purposes.
  For a stronger real-world model, swap `data/emails.csv` for a public
  phishing-email dataset (e.g., from Kaggle) with the same `text,label`
  column format, then re-run `train_model.py`.
- This is an educational project, not a production email filter.
